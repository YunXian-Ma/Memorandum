# Memorandum V1.1 设计方向探索（六个候选 → 精选三个完整版）

## 设计 Spec（三版共同输入）
- **产品**：Memorandum（人物备忘录）V1.1 —— 全局悬浮助手与人物对话数据收集
- **核心场景**：用户在微信 / QQ / 钉钉等第三方聊天应用中，不退出当前应用即可通过全局悬浮球唤出快捷面板：搜索人物、查看人物信息/关系/词条、快速创建新人物（姓名必填、简介选填、创建后自动选中）、主动点击「读取剪贴板」或手动输入对话、编辑后关联人物并保存原始对话到 Room；同时在独立 App 内管理人物、关系、词条、历史对话记录与悬浮助手开关。
- **硬约束**：不支持自动读取后台剪贴板（必须用户主动点击读取），不自动匹配聊天对象（保存前必须手动/创建后明确选中人物），不做 AI 分析与自动提取。
- **输出格式**：1440px 宽展示板 HTML（内含 4-5 台可交互 `AndroidFrame` 手机），每台均可点击交互。

## 选定做完整版的三个方向

### 方向一（dir-1）：白纸叠卡 · 悬浮便签（Hero 主次展示板）
- **逻辑与来源**：最佳设计师视角（延续 V1.0 Cultured Code / 原研哉「白纸 + 发丝线」纸面克制体系，并向跨应用悬浮场景自然延伸）
- **借的是什么**：把跨应用悬浮助手做成「浮在聊天界面上的一张轻盈白色便签纸」，延续极简发丝线分割与衬线人名。
- **不借的、自己长的**：不用重拟物纹理，用微阴影 + 1px 发丝线 + 品牌蓝 `#3478F6` 单一动作色；关系与分类继续用低饱和色点区分。
- **主角素材**：微信聊天界面上浮起的「便签式悬浮助手面板」＋边缘可拖动悬浮球（放大 1.25× 居左主位）。
- **骨架**：`Showboard layout="hero"`，左侧大屏展示跨应用悬浮收集主场景，右侧两列错落排布独立 App 首页（含悬浮助手开关条）、人物详情（词条 + 对话记录双视图）、悬浮快速建人、悬浮球贴边态。
- **胆量花在哪**：把悬浮助手做成几乎无边框的纯白便签纸，直接叠在微信对话之上，靠柔和阴影建立空间层级。
- **form 来自内容的哪里**：记住别人的一句话，就像随手在笔记本里夹进一张白色便签纸。

### 方向二（dir-2）：暗夜浮窗 · 剪贴板工作台（Flow 流程串联展示板）
- **逻辑与来源**：现实参照（借 Raycast Command Palette「顶部输入即搜索 + 底部明确动作确认栏」与 Paste「剪贴板条目左侧色带」机制）
- **借的是什么**：顶部搜索/建人合一的直达框、剪贴板引文左侧色带、底部固定「归属人物 + 保存确认」防呆动作栏。
- **不借的、自己长的**：不借 Raycast 的桌面黑客键帽与纯黑代码风，转为更适合手机夜间/跨应用聊天的深石墨半透明浮窗（`#14171C`）＋电光蓝 `#4D8DFF`＋琥珀 `#F5A623` 剪贴板状态色。
- **主角素材**：暗色悬浮命令工作台，突出「剪贴板读取 → 文本裁剪 → 绑定人物 → 入库」的流程连线。
- **骨架**：`Showboard layout="flow"`，深炭灰底板，按真实使用动线从左到右斜向排列 4 台手机，并用虚线箭头标注每一步流转（「复制聊天消息」→「读取剪贴板并选人」→「无此人时原地快建」→「独立 App 归档回看」）。
- **胆量花在哪**：用深石墨浮窗与浅色聊天背景形成强反差，让用户的视线一秒聚焦在「待收集的对话」上。
- **form 来自内容的哪里**：跨应用收集对话是一个讲求「快进快出」的瞬间动作，工作台就要像呼之即来的快捷键面板。

### 方向三（dir-3）：几何色块 · 记忆活页夹（Closeup 局部特写展示板）
- **逻辑与来源**：秒数轮盘抽中东亚设计 `09 田中一光几何平面构成`（`date +%S` = 56 → `56 % 12 + 1 = 9`），结合 `范式 04 一套语义色`
- **借的是什么**：网格上的方圆几何色块划分视觉重心、粗宋体人名标题、清晰的模块边界与高辨识度语义色（朱红 = 悬浮激活 / 钴蓝 = 剪贴板与主操作）。
- **不借的、自己长的**：不借展览海报的静态宣传内容，将几何色块转化为「独立 App 顶部的悬浮助手控制台」与「悬浮抽屉顶部的三段几何模式切换」。
- **主角素材**：暖米纸 `#F4EFE4` 底板，左侧完整悬浮收集屏 + 中间 2× 放大的「剪贴板收集与快速建人抽屉」核心控件特写。
- **骨架**：`Showboard layout="closeup"`，特写区把「读取剪贴板、编辑文本、新建人物自动选中、保存对话」的完整控件放大呈现。
- **胆量花在哪**：大胆使用朱红 `#D94126` 与钴蓝 `#2554C7` 两块高饱和几何色标，打破常规备忘录的素淡感。
- **form 来自内容的哪里**：每个人的档案就像一只贴了彩色索引标签的活页夹，一眼就能翻到想找的那一页。

## 未做完整版的三个备选方向

1. **候选四 · 液态玻璃浮层（App 02 液态玻璃）**：在微信等第三方 App 上层以高模糊半透明玻璃胶囊承载悬浮球与面板，随底层聊天壁纸隐约透色。
2. **候选五 · 立体触感小磁铁（App 03 玩味 3D 材质）**：用饱和橙/薰衣草色块和带厚度的立体按钮，把「读取剪贴板」做成一下按下去吸住文字的趣味交互。
3. **候选六 · 手账旁注跨页（东亚 12 日式生活杂志密排）**：将人物详情里的词条与历史对话做成杂志式双栏图解，对话旁可附时间刻度与来源印章。
